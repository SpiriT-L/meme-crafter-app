#### meme-crafter-app

# Project idea
The application will receive a random image (either from a pre-prepared set or via an open API with memes) and then provide the user with the ability to add text to it (e.g., top and bottom captions, as in classic memes). Such a project covers the basic principles of working with components, state and events in React, and also allows you to practice working with external libraries, for example, to save the final image.
